Ari Campus AI | Agentic Higher Education Assistant

An enterprise AI campus assistant using retrieval-augmented generation, page-level citations, SQL database tools, machine-learning inquiry classification, and specialized agent routing.

Working capabilities

  • RAG document retrieval with source filename, page, and excerpt
  • SQLAlchemy-backed structured records and inventory workflows
  • Registrar, Finance, Scholarship, Library, IT Support, Guidance, and Laboratory inquiry classification
  • Student enrollment and equipment borrowing with Registrar and Admin approval
  • FastAPI backend, React frontend, scikit-learn model, forecasting, feedback, and human escalation
